# InformationLibrariesSystem
Курсовий проєкт для університету

Данний проєкт має на меті створити інформаційний ресурс для ознайомлення з літературою, наявної в бібліотеці/ках, зареєстрованих в системі. Бібліотекарям надається можливість редагувати зміст літератури в системі та її статусу.
Цей проєкт надасть:
-інформацію щодо наявності літератури в бібліотеках, наявних в системі;
-можливість бібліотекарям надавати інформацію щодо літератури в системі, а саме:
    * назва
    * жанр
    * опис сюжету
    * розмір літератури(кількість сторінок)

Попередньо запланові сутності:
-користувач - перегляд інформації в системі без можливості редагування даних
-бібліотекар - перегляд інформації в системі, можливість редагувати, додавати дані щодо літератури в його бібліотеці
-бібліотека - збірка літератури й бібліотекарів, котрі мають до неї доступ
-адміністратор - власник системи, можливість редагувати та додавати дані бібліотек, бібліотекарів, літератури

План розвитку
1.Створити "скелет" сайту за допомогою HTML та CSS
2.Додати до сайту адаптивність та створити дизайн до нього ж
3.Написати скрипти за допомогою JavaScript, що будуть працювати з серверною частиною проєкту
4.Впровадити React-фреймворк JavaScript в цей проєкт
5.Налаштувати взаємодію з серверною частиною проєкту за допомогою Node.Js
6.Створити бази даних, налаштувати взаємодію з серверною частиною проєкту
7.Налаштувати безпеку та продуктивність проєкту
